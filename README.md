# INCLUSIVECONNECT
### *"Making Workplace Information Accessible to Everyone"*
**Multi-Organization Workplace Communication & Accessibility Platform**

---

## Quick Start Instructions

### 1. Start the Backend Server (Port 5000)
```bash
cd backend
npm install
npm start
```

### 2. Start the Frontend Application (Port 5173)
```bash
cd frontend
npm install
npm run dev
```

Open **`http://localhost:5173`** in your browser.

## Core Capabilities

1. **Multi-Organization Workspaces:**
   * Multiple organizations can use the single platform simultaneously with isolated announcements, employees, and acknowledgement tracking.
   * New organizations can register their own workspace anytime.
2. **AI Simplification & Multilingual Translation:**
   * Converts complex English announcements into simple bullet points and translates them into **Telugu, Hindi, and Tamil**.
3. **Preferred Language Dropdown & Audio Narration:**
   * Employees choose their preferred language from a clean dropdown in their dashboard and can listen to announcements using Text-to-Speech.
4. **Acknowledgement Tracking:**
   * Employees confirm reading announcements, and Organization Admins track Acknowledged vs Pending employees in real time.
